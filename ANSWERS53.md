# Ответы по лекции 53

1. **Что такое JavaScript?** Язык программирования для интерактивности сайта: кнопок, форм, меню и вычислений.
2. **Что такое автоматическая проверка JavaScript?** Анализ исходников инструментом по выбранным правилам для обнаружения ошибок и потенциальных проблем.
3. **Какие ошибки бывают в JavaScript?** Синтаксические ошибки, неопределённые идентификаторы, неверное использование переменных, неиспользуемые значения и ошибки логики.
4. **Что такое статический анализ?** Проверка исходного кода без запуска пользовательских функций сайта.
5. **Для чего нужен ESLint?** Для проверки JavaScript и обнаружения нарушений настроенных правил.
6. **Чем ESLint отличается от Stylelint?** ESLint анализирует JavaScript; Stylelint — CSS.
7. **Какие проблемы обнаруживает ESLint?** Например, неопределённые и неиспользуемые переменные, синтаксические ошибки; набор зависит от конфигурации.
8. **Для чего нужен eslint.config.js?** Он задаёт проверяемые файлы, язык, глобальные переменные и правила ESLint.
9. **Что делает npm install --save-dev eslint?** Устанавливает ESLint как зависимость разработки и обновляет package.json и lock-файл.
10. **Что делает npx eslint "**/*.js"?** Проверяет все файлы с расширением .js в проекте и вложенных каталогах; node_modules по умолчанию исключён.
